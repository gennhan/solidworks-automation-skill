# v2.0.1 — Synchronized Skill Package and CAD Studio Release

The skill was previously at version 2.0.0 and the desktop app at version 0.3.4; starting with this release, both are unified at 2.0.1 to avoid missing desktop update manifests on the latest release or mismatched versions.

## Download and Upgrade

- **CAD Studio Installer**: Download `CAD-Studio-2.0.1-Setup-x64.exe`, close CAD Studio, and run the installer. Existing desktop installations with signed update support can also check for updates in-app; if a prior update check failed due to a missing manifest on the latest release, download the installer directly.
- **CAD Studio Portable**: Download `CAD-Studio-2.0.1-Windows-x64-Portable.zip`, extract it to a new directory, and launch `CAD Studio.exe`. No separate skill import is required because the matching runtime is already bundled.
- **Agent Skill Package**: Download `SolidWorks-Automation-Skill-2.0.1.zip`, containing `solidworks-automation/SKILL.md`, the MCP server, scripts, dependency manifests, and installers. Import the entire `solidworks-automation` folder into your client. Back up any existing manual installation before updating to keep your configuration and models; Git-based installations can continue using the installer's fast-forward update.
- **Verification**: `SHA256SUMS.txt` covers all release assets; the installer also includes `.sig`, and `latest.json` provides the download URL and signature for the existing updater. This release continues using the 0.3.4 update public key and application identifier.

Native CAD operations still require a locally installed and licensed copy of SolidWorks. The live-machine acceptance target for newly added capabilities is SolidWorks 2026 SP1.1; see the README and User Manual for Python/Node prerequisites and on-demand environment provisioning.

## Highlights

- **Delivery Authenticity** (#52, #54, #68): Production executors enforce a unified current-run file gate; stale files are rejected for delivery, and missing baselines, truncated scans, or out-of-scope files transition to review required. Completed pre-execution worker evidence capture, scan scope, file-type coverage, and frontend tri-state evaluation.
- **Geometric Edge Selection** (#67, #69): Fixed edge-length and circle-diameter readback; covers short arcs, full circles without vertices, reversed parameters, non-finite values, error propagation, and pywin32 compatibility paths.
- **SW2026 Assembly and Drawing Increments**: Includes mainline-accepted assembly copy-with-rename and mate reference verification, structured GD&T drafting, composite frames, common datums, and projected tolerance zones; consult `capabilities.yaml` and corresponding reference docs for exact scope—design and manufacturing decisions still require engineering review.
- **API Verification**: Covers local help, official docs, local cache, fallback lookup paths, and on-demand environment setup; lookup evidence never replaces live CAD verification.
- **Release Consistency**: The standalone skill package and desktop-bundled skill share a single runtime manifest verified file-by-file, including .NET host source and DRC config. The skill ZIP includes the source commit and a per-file SHA-256 manifest.

These fixes have passed SolidWorks 2026 live-machine regression; the release pipeline also verifies Python, frontend, Rust, signed updater contracts, and portable/installer startup. This release does not claim re-testing across all SolidWorks versions, nor does file freshness certify dimensional or manufacturing conformance.
