# v2.1.1 — Engineering Stage Review

- **Inspect Stage Reviews**: View acceptance criteria, open questions, and human review status for each stage directly in the CAD Studio task execution pane and queue.
- **Flag Impacted Results After Edits**: Editing requirements or length/width/height/wall-thickness in the workbench, or issuing an explicit chat instruction to change requirements or key dimensions, marks affected prior results. For example, "change hole diameter to 8 mm" marks downstream stages starting from the holes/slots stage along the dependency graph while keeping requirements and base modeling intact. Regular follow-up questions, hypotheticals, and negations do not trigger marking.
- **Preserve History**: Prior files and original review records remain inspectable. Chat-driven changes take effect once successfully queued, and review state persists across restarts.
- **Fix Desktop Agent Launch**: The worker closes standard input for non-interactive agents so leftover stdin pipes from the launcher do not block tasks. Codex can run from the skill directory shipped with the installer while task approval and sandbox policies remain active.
- **Verify Current-Run Dimensional Evidence**: The delivery ledger records pre-execution hashes of JSON measurement reports so only newly generated or modified reports qualify for dimensional acceptance.
- **Preserve Follow-Up Context**: Subsequent conversation turns use summarized message snippets from history, while full diagnostics remain available in task records.

## Download and Upgrade

- **CAD Studio**: Download `CAD-Studio-2.1.1-Setup-x64.exe`. v2.1.0 users can check for updates inside CAD Studio, or close the app and run the new installer over the existing install directory. Extract the portable archive to a new directory.
- **MCPB**: Import `SolidWorks-Automation-Skill-2.1.1.mcpb` into an MCPB-compatible client. If `uv` is missing, run `winget install --id astral-sh.uv -e` and restart the client. The `-smithery` package is for the Smithery tool catalog.
- **Standalone Skill**: Download `SolidWorks-Automation-Skill-2.1.1.zip` and import the `solidworks-automation` folder.

The installer, portable package, Skill ZIP, and MCPB bundles all ship the same runtime version. Verify downloads with `SHA256SUMS.txt`. Native operations still require a locally installed and licensed SolidWorks.
