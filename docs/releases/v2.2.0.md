# v2.2.0 — Live Preview, Drafting Inspection, and Connection Reliability

This release consolidates PRs/issues #79, #80, #81, #86, #87, #88, #89, and #90 following v2.1.1. The standalone Skill, standard MCPB, Smithery MCPB, CAD Studio installer, and portable build all ship the same v2.2.0 runtime.

## Additions and Improvements

- **SolidWorks Live Execution Preview**: CAD Studio can monitor modeling progress by capturing only the target SolidWorks window; capture failures display preview unavailable rather than falling back to other windows or the full desktop.
- **AutoCAD CJK Fonts and Native Previews**: Improved font selection and verification of localized title blocks, dimensions, viewports, and native export results.
- **DXF Drafting Inspection Report**: Configures rules by sheet size and project template to generate reviewable inspection reports; dimension clearance, text overlap, and manufacturing release remain subject to human review.
- **Installation and Job Reliability**: Strengthened installer safeguards, CAD health probing, and execution result fault tolerance.
- **Codex Read-Only Tasks**: Preserves `read-only` mode when explicitly selected instead of upgrading it to `workspace-write`.
- **Rib Feature**: Completed `InsertRib` parameters and returns the newly added rib via feature-tree diff; returns empty when not created instead of falsely returning an existing rib. Preserves legacy two-sided thickness semantics for `direction`.
- **Optional Instance Attachment Fallback**: Disabled by default. When `SW_ATTACH_EXISTING_DISPATCH=1` is explicitly set, attempts versioned `Dispatch` on ROT lookup failure and validates PID, actual version, and pre/post process lists. Attachment preserves the user's window, documents, and instance ownership; halts on identity mismatch without auto-retrying or exiting unknown instances. In some environments `Dispatch` may still start another process, and post-hoc verification cannot prevent the constructor call itself.
- **Hole Creation Failure Diagnostics**: When a circular hole cut returns empty, provides `SW_HOLE_NOT_CREATED`, post-failure sketch/selection/body state, and `retryable=false`; never reverses cut direction or retries write operations automatically.
- **Preserved Stage Review**: Explicit requirement or key-dimension edits in the workbench or chat continue marking impacted downstream stages without triggering on ordinary follow-up questions.

## Verification Scope and Known Limitations

The latest live-machine acceptance targeted SolidWorks 2026 SP1.1: single/two-sided ribs, second rib, and save-and-reopen; 16 connection and window-state comparison cases; 10 passing through-hole cases plus direct API/MCP failure diagnostics. See verification records for [rib feature](../rib-sw2026-regression.md), [connection fallback](../rot-sw2026-regression.md), and [reopened through-hole](../hole-reopen-regression.md).

**The SW2024 build 32.5.0 issue originally reported in #82 is not yet confirmed fixed, and the issue remains open.** Passing the SW2026 regression does not prove that the SW2024 scenario is resolved. The Codex fix verified final sandbox argument selection; OS-level sandbox comparison on the local machine did not obtain valid isolation evidence, so no extra isolation guarantee is claimed.

Native CAD operations still require locally installed and licensed software. Advanced geometry, varied models, and manufacturing delivery continue to require task-specific review.

## Download and Upgrade

- **CAD Studio Installer**: Download `CAD-Studio-2.2.0-Setup-x64.exe`. v2.1.1 users can check for updates in-app, or close CAD Studio and run the new installer over the existing install directory; upgrade acceptance covers in-place installation and app-data preservation.
- **CAD Studio Portable**: Download `CAD-Studio-2.2.0-Windows-x64-Portable.zip` and extract it to a new folder to avoid overwriting a running binary.
- **Standalone Skill**: Download `SolidWorks-Automation-Skill-2.2.0.zip` and import the `solidworks-automation` folder.
- **Standard MCPB**: Import `SolidWorks-Automation-Skill-2.2.0.mcpb` in an MCPB-compatible Windows client, then restart or reconnect the MCP service.
- **Smithery MCPB**: Use `SolidWorks-Automation-Skill-2.2.0-smithery.mcpb`.

MCPB continues managing Python 3.12 and locked dependencies via `uv` without bundling Python. When `uv` is missing, the launcher prints installation guidance to stderr while keeping stdout dedicated to the MCP protocol. Run the command below to install `uv`, then quit and reopen the client; initial Python and dependency resolution requires internet access.

```powershell
winget install --id astral-sh.uv -e
```

Verify downloaded files against `SHA256SUMS.txt` on the same release page. The installer's update signature file and `latest.json` are published alongside the release using the existing update public key.
