# v2.1.0 — MCPB and LM Studio Local Assistant

- **CAD Studio**: Download the installer `CAD-Studio-2.1.0-Setup-x64.exe`. v2.0.1 users can check for updates inside CAD Studio, or close the app and run the new installer over the existing install directory. Extract the portable archive to a new directory.
- **MCPB**: Download `SolidWorks-Automation-Skill-2.1.0.mcpb` and import it into a Windows client that supports MCPB. If logs report missing `uv`, run `winget install --id astral-sh.uv -e`, then quit and reopen the client. First launch fetches Python and locked dependencies. The `-smithery` package is intended for the Smithery tool catalog.
- **Standalone Skill**: Download `SolidWorks-Automation-Skill-2.1.0.zip` and import the `solidworks-automation` folder into your client. Both MCPB bundles and the desktop package ship the same skill runtime version.

CAD Studio adds **LM Studio Local Q&A and Task Planning**. Load a chat model in LM Studio 0.4 or newer, start the local API server, and verify the connection in the CAD Studio panel. Q&A supports contextual follow-ups, while Task Planning displays open questions, execution steps, and acceptance criteria. Plans are intended for human review; actual CAD actions are submitted through a separate AI execution conversation.

Native SolidWorks operations still require a local licensed installation. Recent regressions target SolidWorks 2026 SP1.1 as the baseline, with additional 2024 live-machine records for select capabilities (see `capabilities.yaml`). Unlisted versions and capabilities require separate verification.

Windows installer regressions ran on a clean GitHub-hosted Windows Server 2022 runner covering clean install, launch, in-place upgrade from the public v2.0.1 installer, and app-data preservation. Signatures and update manifests are automatically verified. Verify downloads against `SHA256SUMS.txt`.
